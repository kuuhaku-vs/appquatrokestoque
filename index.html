CELULAR

Usar o NOVA no celular

Com o celular no mesmo Wi-Fi da empresa, aponte a câmera para o código ou digite o endereço no navegador:

  1. Entre com seu usuário do Protheus e marque Mantenha-me conectado.
  2. Para virar um ícone: Android/Chrome ⋮ → Adicionar à tela inicial; iPhone/Safari ⎋ → Adicionar à Tela de Início.
  3. Este computador precisa ficar ligado com a janela do NOVA aberta.

O NOVA está aberto só para este computador. Para liberar os celulares:

  1. Feche a janela preta do servidor do NOVA.
  2. Abra INICIAR_NOVA_REDE.bat (em vez de INICIAR_NOVA.bat).
  3. Se o Windows perguntar, clique em Permitir para Redes privadas.
  4. Volte aqui em 📱 Usar no celular para ver o código QR.
