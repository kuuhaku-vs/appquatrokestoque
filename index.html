CELULAR

Usar o NOVA no celular

Com o celular no mesmo Wi-Fi da empresa, aponte a câmera para o código ou digite o endereço no navegador:

  1. Entre com seu usuário do Protheus e marque Mantenha-me conectado.
  2. Para virar um ícone: Android/Chrome ⋮ → Adicionar à tela inicial; iPhone/Safari ⎋ → Adicionar à Tela de Início.
  3. Este computador precisa ficar ligado com a janela do NOVA aberta (NOVA.exe).

O NOVA está aberto só para este computador. Para abrir no celular pelo Wi-Fi, abra o NOVA pelo NOVA.exe (atalho NOVA Local). Se o Windows perguntar, clique em Permitir para Redes privadas.

Também dá para publicar no GitHub Pages e abrir pelo endereço do site (veja o README).
